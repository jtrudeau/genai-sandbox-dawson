# Workshop Prompts

Use this page with the workshop.
The prompts are here to support the session, not to turn it into a prompt library.

The main lesson is simple: start with a specific task and enough context to judge whether the response fits your situation.

If you have to translate the language yourself, simplify it before the workshop.

## How to Use This Page

Use this page in a simple sequence:

- choose one Set 1 prompt for the demonstration
- use Set 2 for the first hands-on activity
- choose one Set 3 prompt if time allows
- use Rapid Start when participants need a quicker way in
- do not try to use every prompt in one session

In a quick walkthrough, this page worked best when facilitators used one demo, one shared activity, and only one follow-up prompt.

## Write a Short Context Before You Ask AI

<div className="context-packet">
Before anyone asks AI, write down these five things:

1. **Task:** What do I want help with?
2. **Context:** What course, topic, group, or setting is this for?
3. **What you want the response to do:** What do you want it to help you do?
4. **Limits:** What should AI not do? What stays human?
5. **Check:** What will I review before I use anything?
</div>
<div className="prompt-warning">
  <p>If these notes stay vague, the response will stay vague too.</p>
</div>

<p>Providing specific context can significantly improve the quality of the output the AI provides. Keep the first example small enough to illustrate the point.</p>

## Set 1: Facilitator Demonstration Prompts

Use one of these for the live demo.
Start with a shorter version first, then add context in front of the group.
The point is to show the difference between a vague ask and the same ask with more context.

### Scenario A: Discussion Prompts (Social Sciences/Humanities)
<WorkshopPrompt
  description="Use this to show how added context can turn a broad discussion task into prompts that are more specific and easier to discuss."
  prompt={`I'm a college sociology instructor preparing for a class discussion on social stratification. I typically create 3-4 discussion prompts per class, but they often feel repetitive or too broad.

Help me generate 5 alternative discussion prompts for a 75-minute class on social stratification.

Context:
- Students: second-year college, mixed majors (intro sociology)
- They have read a chapter on class, income inequality, and social mobility
- Learning goal: connect abstract concepts to patterns in their own communities
- My current issue: prompts are often too generic (for example, "What is social stratification?")

I want prompts that:
- are specific enough to spark interpretation or disagreement
- connect theory to students' lived experiences
- ask students to analyze, not just describe
- can be discussed in 10-15 minutes in small groups

Return your response as:
1) Student-facing prompt text
2) Why it is likely to produce stronger discussion
3) What tension, disagreement, or interpretive fork it opens
4) What to watch for when facilitating`}
/>

### Scenario B: Scaffolded Practice Problems (STEM)
<WorkshopPrompt
  description="Use this to show how added context can improve progression, challenge, and teacher-side checking."
  prompt={`I teach introductory calculus at the college level. Many students struggle with limits. They can follow examples but freeze on independent practice.

Help me create a scaffolded sequence of 4 practice problems on algebraic limits, increasing in difficulty.

Context:
- Topic: algebraic limits (not graphical or numerical methods)
- Students: first-year college, many with math anxiety
- Current issue: textbook progression jumps too quickly from simple to complex
- Goal: build confidence while maintaining challenge

For each problem:
1. State the problem clearly
2. State the new challenge introduced compared to the previous problem
3. Provide one instructor hint for students who get stuck

The first problem should be straightforward. The fourth should be challenging but solvable with covered techniques.

Also provide a full correct worked solution for the fourth problem so I can verify accuracy.

Return your response as:
1) Problem set
2) Progression rationale
3) Worked solution for problem 4
4) Quick facilitation notes`}
/>

### Scenario C: Short Reflection Prompts (Any Discipline)
<WorkshopPrompt
  description="Use this to show how added context can make reflection prompts more specific and easier to use."
  prompt={`I teach a professional writing course and want to increase reflective practice without adding grading load.

Help me create 5 one-minute reflection prompts for the last 3-5 minutes of class.

Context:
- Course: professional writing (business communication, resumes, reports)
- Students: third-year college, career-focused
- Goal: strengthen metacognition about writing choices and process
- Current issue: I keep using the same generic reflection question

Use these when participants need a quicker way in or get stuck.
These prompts carry more of the context inside the request itself, so participants can get to a first draft they can work with faster.
The tradeoff is that the result will usually be more generic than the main path.
If something looks promising, add more context and try again with one of the fuller prompts above.

## Suggested Timing

Suggested timing with these prompts:

- Set 2 shared activity: 12-15 minutes
- Pair exchange: 8-10 minutes
- Set 3 chosen prompt: 10-12 minutes in a 90-minute workshop
- Rapid Start: use when you need a shorter final activity without rushing the fuller prompts

## Adaptation Notes

Adjust prompts by:

- narrowing the task to one discipline or program
- adding departmental or institutional policy and integrity constraints when needed
- adding examples, files, or existing materials only when they clearly help
- keeping one clear place in the process where people review the result themselves
