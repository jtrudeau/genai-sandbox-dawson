# Workshop Prompts

This page contains the prompt sets used in the 90-minute workshop.

Use these as working drafts. They are designed to be edited for local context, not treated as fixed scripts.

## How to Use This Page

- Facilitators use Set 1 for a live demonstration.
- All participants use Set 2 in the first activity.
- Participants choose one Set 3 scenario in the second activity.

## Prompt Quality Checks

Before you run a prompt, make sure it includes:

- a bounded task (one run, one context)
- specific context (discipline, level, challenge)
- quality criteria you already use
- an evidence plan (what you will collect)
- a risk and stop signal (when to pause or stop)

---

## Set 1: Facilitator Demonstration Prompts

Choose one scenario for the demonstration. Run it in advance or live.

### Scenario A: Discussion Prompts (Social Sciences/Humanities)
<WorkshopPrompt
  title="Facilitator Demo: Discussion Prompts"
  description="Expected output: 5 discussion prompts with rationale. Use this to model how to evaluate fit and quality in context."
  prompt={`I'm a college sociology instructor preparing for a class discussion on social stratification. I typically create 3-4 discussion prompts per class, but they often feel repetitive or too broad.

Help me generate 5 alternative discussion prompts for a 75-minute class on social stratification.

Context:
- Students: second-year college, mixed majors (intro sociology)
- They have read a chapter on class, income inequality, and social mobility
- Learning goal: connect abstract concepts to patterns in their own communities
- My current issue: prompts are often too generic (for example, "What is social stratification?")

For each prompt, briefly explain why it is likely to produce stronger discussion.

I want prompts that:
- are specific enough to spark debate but open enough for multiple perspectives
- connect theory to students' lived experiences
- ask students to analyze, not just describe
- can be discussed in 10-15 minutes in small groups

Return your response as:
1) Prompt text
2) Why it works
3) What to watch for when facilitating`}
/>

### Scenario B: Scaffolded Practice Problems (STEM)
<WorkshopPrompt
  title="Facilitator Demo: Scaffolded Practice Problems"
  description="Expected output: 4 scaffolded problems with progression notes and one hint per problem."
  prompt={`I teach introductory calculus at the college level. Many students struggle with limits. They can follow examples but freeze on independent practice.

Help me create a scaffolded sequence of 4 practice problems on algebraic limits, increasing in difficulty.

Context:
- Topic: algebraic limits (not graphical or numerical methods)
- Students: first-year college, many with math anxiety
- Current issue: textbook progression jumps too quickly from simple to complex
- Goal: build confidence while maintaining challenge

For each problem:
1. State the problem clearly
2. Name the new challenge introduced compared to the previous problem
3. Provide one instructor hint for students who get stuck

The first problem should be straightforward. The fourth should be challenging but solvable with covered techniques.

Return your response as:
1) Problem set
2) Progression rationale
3) Quick facilitation notes`}
/>

### Scenario C: Low-Stakes Reflection Prompts (Any Discipline)
<WorkshopPrompt
  title="Facilitator Demo: Reflection Prompts"
  description="Expected output: 5 short reflection prompts with implementation suggestions."
  prompt={`I teach a professional writing course and want to increase reflective practice without adding grading load.

Help me create 5 one-minute reflection prompts for the last 3-5 minutes of class.

Context:
- Course: professional writing (business communication, resumes, reports)
- Students: third-year college, career-focused
- Goal: strengthen metacognition about writing choices and process
- Current issue: I keep using the same generic reflection question

For each prompt:
1. Provide exact wording for students
