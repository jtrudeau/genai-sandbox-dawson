Workshop Prompts

Use this page with the workshop. The prompts are here to support the session, not to turn it into a prompt library.

The main lesson is simple: start with a specific task and enough context to judge whether the response fits your situation.

Facilitator note: test this page before using it live

Run one quick walkthrough first. Treat it as a short simulation: pick a likely participant role, move through one demo, the shared activity, and one follow-up prompt, and see whether the path stays clear without extra explanation. If you have to translate the language yourself, simplify it before the workshop.

How to Use This Page

Use this page in a simple sequence:

  • choose one Set 1 prompt for the demonstration
  • use Set 2 for the first hands-on activity
  • choose one Set 3 prompt if time allows
  • use Rapid Start when participants need a quicker way in
  • do not try to use every prompt in one session

In a quick walkthrough, this page worked best when facilitators used one demo, one shared activity, and only one follow-up prompt.

Write a Short Context Before You Ask AI

Before anyone asks AI, write down these five things:

  1. Task: What do I want help with?
  2. Context: What course, topic, group, or setting is this for?
  3. What you want the response to do: What do you want it to help you do?
  4. Limits: What should AI not do? What stays human?
  5. Check: What will I review before I use anything?

If these notes stay vague, the response will stay vague too.

Keep the first example small enough to illustrate the point.

Set 3 Rapid Start

Use these when participants need a quicker way in or get stuck. These prompts carry more of the context inside the request itself, so participants can get to a first draft they can work with faster. The tradeoff is that the result will usually be more generic than the main path. If something looks promising, add more context and try again with one of the fuller prompts above.

Teaching Materials

Facilitator cue: use when participants need a quick materials-design test tied to one topic.

I want one small AI-supported test for a teaching-material task.

Keep the response concise. Use one short bullet per requested item.

Use these notes as the source of truth:
- Task: [material I want to create or revise]
- Context: [discipline, topic, learner group, setting]
- What you want the response to do: [what you want the response to help you do]
- Limits: [what AI should not do, what stays human]
- Check: [how I will judge usefulness]

If any note is still bracketed or too vague, ask one brief clarification question and stop.

Return:
- short summary
- one prompt or brief I can use now
- what I should review carefully
- what I could look for to judge whether it helped
- one reason to change course or stop
- one next step if it seems worthwhile

Sense-Making and Reflection

Facilitator cue: use when participants want reasoning support without outsourcing thinking.

I want one small AI-supported test for sense-making or reflection.

Keep the response concise. Use one short bullet per requested item.

Use these notes as the source of truth:
- Task: [reflection or reasoning task]
- Context: [discipline, learner group, setting]
- Useful result: [what stronger thinking or reflection would look like]
- Limits: [what learners still have to do themselves]
- Check: [how I will judge usefulness]

If any note is still bracketed or too vague, ask one brief clarification question and stop.
Prefer scaffolds, questions, or partial structures over completed student answers unless I explicitly ask for a model example.

Return:
- short summary
- learner-facing prompt or instructions
- what learners still need to do for themselves
- what I should review carefully
- what I could look for to judge whether it helped
- one reason to change course or stop
- one next step if it seems worthwhile

Expectations and Integrity

Facilitator cue: use when participants are working on clearer AI-use boundaries.

I want one small AI-supported test for making AI-use expectations clearer.

Keep the response concise. Use one short bullet per requested item.

Use these notes as the source of truth:
- Task: [boundary, statement, or expectations task]
- Context: [discipline, learner group, setting]
- What you want the response to do: [what kind of understanding you want to support]
- Limits: [what must stay explicit and non-delegated]
- Check: [how I will judge usefulness]

If any note is still bracketed or too vague, ask one brief clarification question and stop.
Do not invent institutional policy or legal requirements. Say what still needs confirmation from the department or institution.

Return:
- short summary
- learner-facing language draft
- what still needs confirmation from the department or institution
- what I should review carefully
- what I could look for to judge whether it helped
- one reason to change course or stop
- one next step if it seems worthwhile

Suggested Timing

Suggested timing with these prompts:

  • Set 2 shared activity: 12-15 minutes
  • Pair exchange: 8-10 minutes
  • Set 3 chosen prompt: 10-12 minutes in a 90-minute workshop
  • Rapid Start: use when you need a shorter final activity without rushing the fuller prompts

Adaptation Notes

Adjust prompts by:

  • narrowing the task to one discipline or program
  • adding departmental or institutional policy and integrity constraints when needed
  • adding examples, files, or existing materials only when they clearly help
  • keeping one clear place in the process where people review the result themselves
