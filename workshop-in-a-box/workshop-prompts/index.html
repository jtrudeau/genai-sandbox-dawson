Workshop Prompts

This page contains the prompt sets used in the 90-minute workshop.

Use these as working drafts. They are designed to be edited for local context, not treated as fixed scripts.

How to Use This Page

  • Facilitators use Set 1 for a live demonstration.
  • All participants use Set 2 in the first activity.
  • Participants choose one Set 3 scenario in the second activity.

Prompt Quality Checks

Before you run a prompt, make sure it includes:

  • a sandboxed task (one run, one context)
  • specific context (discipline, level, challenge)
  • quality criteria you already use
  • an evidence plan (what you will collect)
  • a risk and stop signal (when to pause or stop)

Set 1: Facilitator Demonstration Prompts

Choose one scenario for the demonstration. Run it in advance or live.

Scenario A: Discussion Prompts (Social Sciences/Humanities)

Facilitator Demo: Discussion Prompts

Expected output: 5 discussion prompts with rationale. Use this to model how to evaluate fit and quality in context.

Scenario B: Scaffolded Practice Problems (STEM)

Facilitator Demo: Scaffolded Practice Problems

Expected output: 4 scaffolded problems with progression notes and one hint per problem.

Scenario C: Low-Stakes Reflection Prompts (Any Discipline)

Facilitator Demo: Reflection Prompts

Expected output: 5 short reflection prompts with implementation suggestions.

Set 3 (Rapid Mode): Short-Form Scenario Prompts

Use these when time is tight and you need a fast first draft in 5-8 minutes.

Scenario A (Rapid): Teaching Materials

Facilitator cue: Use when participants need a quick materials-design test tied to one topic.

Design one sandboxed experiment for using AI to create [discussion prompts / practice problems / worked examples / assignment variations / reading questions] for [discipline + topic].

Include:
- experiment summary
- one prompt I can run now
- 3 evaluation criteria
- evidence to collect
- one risk + one stop signal
- a continue / modify / stop decision rule

Scenario B (Rapid): Feedback and Assessment

Facilitator cue: Use when participants are focused on feedback workflow pressure and consistency.

Design one sandboxed experiment for using AI to support [draft feedback / problem-solving feedback / rubric interpretation / exemplar commentary] in [course + assessment type], without replacing instructor judgment.

Include:
- experiment summary
- one prompt with guardrails
- AI boundaries (does / does not do)
- 3 evaluation criteria
- evidence to collect
- one risk + one stop signal
- a continue / modify / stop decision rule

Scenario C (Rapid): Sense-Making and Reflection

Facilitator cue: Use when participants want student reasoning support without outsourcing thinking.

Design one sandboxed experiment for using AI to support student [concept explanation / misconception checking / reflective writing / exam wrapper] in [course + activity].

Include:
- experiment summary
- student-facing prompt
- student use/non-use instructions
- 3 evaluation criteria
- evidence to collect
- one risk + one stop signal
- a continue / modify / stop decision rule

Scenario D (Rapid): Interaction and Discussion

Facilitator cue: Use when participants want to test discussion quality and participation shifts.

Design one sandboxed experiment for using AI to improve classroom discussion in [course + session type], without flattening student voices.

Include:
- experiment summary
- one prompt I can run
- when AI is used (before / during / after class)
- 3 discussion-quality criteria
- evidence to collect
- one risk + one stop signal
- a continue / modify / stop decision rule

Scenario E (Rapid): Expectations and Integrity

Facilitator cue: Use when participants are working on clearer AI-use boundaries for students.

Design one sandboxed experiment for making AI-use expectations explicit for [course + assignment].

Include:
- experiment summary
- student-facing language draft
- short facilitation plan
- 3 indicators of improved understanding
- evidence to collect
- one risk + one stop signal
- a continue / modify / stop decision rule

Facilitation Timing

Suggested timing with these prompts:

  • Set 2 individual run: 10-15 minutes
  • Small-group exchange: 5-7 minutes
  • Set 3 scenario run: 15-20 minutes
  • Scenario synthesis and whole-group share: 10-15 minutes

Adaptation Notes

For department-specific workshops, narrow the prompt set and pre-fill disciplinary context.

For broad cross-disciplinary runs, keep all scenarios and group participants by selected scenario during synthesis.

After the Workshop

Ask participants to save outputs, choose one sandboxed run, and continue with:

  • Run an Experiment
  • Welcome
  • Interactive Planner

The prompts support experimentation. The educational value comes from faculty judgment, documentation, and reflection.
