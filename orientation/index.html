Orientation

GENAI Sandbox Orientation – Faculty Simulation Showcase

Last updated: 2025-09-21

1. Welcome & Framing (5 min)

  • Highlight sandbox goals: explore, document, share.
  • Introduce streamlined templates + quickstart.
  • Present faculty use case menu to inspire selection (Use Cases).

2. Simulation Highlights (15 min)

  • Humanities: AI summaries + student critique (show workflow snapshot and reflection gains).
  • Industrial Design: GPT-5 co-designer workflow (constraint checklist with lab readiness).
  • Physics MCQ: AI + SME question design (QA checklist and analytics loop).
  • CS Code Review: Low-stakes Claude/ChatGPT assist (before/after code diff and turnaround data).
  • Mention archived extras (Applied Arts, lab prep) as reference.

3. Hands-On Walkthrough (10 min)

  • Quickstart demo: choose a persona, fill exploration goal, map workflow.
  • Show how to capture outputs in faculty template (Goal → Workflow → Evidence → Reflection → Guardrails).
  • Invite participants to mark interest in specific use cases or propose new ones.

4. Resource Review (5 min)

  • Point to resource hub and templates (Guides).
  • Share exemplar files from the Faculty simulations library (workflow, verification, code review packets) and highlight any relevant co-curricular projects that illustrate adjacent experimentation.
  • Explain archive access for legacy templates (Examples Archive).

5. Next Steps & Support (5 min)

  • Confirm monthly pulse check and Oct 22 workshop.
  • Review guardrail reminders (transparency, privacy, licensing, safety sign-offs) using the checklist in Faculty Sandbox Template.
  • Outline how to log new use cases/feedback (coordination contact, tracker update) using Faculty Sandbox Use Cases and monthly pulse.

Appendix Assets

  • Slide deck placeholders linking to sample artifacts (to be built).
  • Orientation demo files (PDF exports, Loom links) – pull from Faculty Examples once finalized and add new co-curricular references separately.

Demo Inserts

  • AI Making Challenge: Showcase data visualization simulation (AI Making Examples) with Prompt & Validate loop (prompt log, accessibility check, intervention).
  • Media art duo example as optional alternate.
